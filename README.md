## Overview

sforzando is a free, high-quality SFZ player with complete SFZ 2.0 support including modulation, effects opcodes, and MIDI CC targeting, enabling playback of the vast community SFZ library.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plogue sforzando** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **SFZ 2.0 Support** | Full specification support including all modulation and control opcodes |
| **ARIA Engine** | High-performance ARIA sample engine with polyphonic voice management |
| **Effect Opcodes** | Built-in reverb, chorus, EQ, and filter effects from SFZ spec |
| **MIDI CC Mapping** | Assign any SFZ CC target to external hardware controllers |
